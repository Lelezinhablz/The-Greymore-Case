PSX Cassette Tape
=================

Authentic PS1-style low-poly game asset.

Triangles: 118
Objects: cassette_tape (118 tris)
Size: 0.10 x 0.06 x 0.01 m (real-world scale, 1 unit = 1 metre)
Texture: 64x64 px, 20 colours, one atlas (textures/psx_cassette_tape_diffuse.png)
Use nearest-neighbour ("point") filtering and no mipmaps for the authentic look.
Pivot: bottom centre.
Axes: FBX/OBJ are Y-up, -Z forward (Unity / Unreal / Godot ready). GLB follows glTF conventions.

Files:
  psx_cassette_tape.fbx
  psx_cassette_tape.obj
  psx_cassette_tape.mtl
  psx_cassette_tape.glb
  collision/psx_cassette_tape_collision.fbx
  psx_cassette_tape.blend
  textures/psx_cassette_tape_diffuse.png

collision/ holds a simple convex collision mesh (UCX_ prefix = Unreal custom collision).
