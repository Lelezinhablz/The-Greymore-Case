PSX Pickup Marker
=================

Authentic PS1-style low-poly game asset.

Triangles: 32
Objects: pickup_marker (32 tris)
Size: 0.50 x 0.50 x 0.01 m (real-world scale, 1 unit = 1 metre)
Texture: 64x64 px, 11 colours, one atlas (textures/psx_pickup_marker_diffuse.png)
Use nearest-neighbour ("point") filtering and no mipmaps for the authentic look.
Pivot: bottom centre.
Axes: FBX/OBJ are Y-up, -Z forward (Unity / Unreal / Godot ready). GLB follows glTF conventions.

Files:
  psx_pickup_marker.fbx
  psx_pickup_marker.obj
  psx_pickup_marker.mtl
  psx_pickup_marker.glb
  collision/psx_pickup_marker_collision.fbx
  psx_pickup_marker.blend
  textures/psx_pickup_marker_diffuse.png

collision/ holds a simple convex collision mesh (UCX_ prefix = Unreal custom collision).
