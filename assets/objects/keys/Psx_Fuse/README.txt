PSX Fuse
========

Authentic PS1-style low-poly game asset.

Triangles: 108
Objects: cartridge_fuse (108 tris)
Size: 0.08 x 0.02 x 0.02 m (real-world scale, 1 unit = 1 metre)
Texture: 64x64 px, 17 colours, one atlas (textures/psx_fuse_diffuse.png)
Use nearest-neighbour ("point") filtering and no mipmaps for the authentic look.
Pivot: bottom centre.
Axes: FBX/OBJ are Y-up, -Z forward (Unity / Unreal / Godot ready). GLB follows glTF conventions.

Files:
  psx_fuse.fbx
  psx_fuse.obj
  psx_fuse.mtl
  psx_fuse.glb
  collision/psx_fuse_collision.fbx
  psx_fuse.blend
  textures/psx_fuse_diffuse.png

collision/ holds a simple convex collision mesh (UCX_ prefix = Unreal custom collision).
